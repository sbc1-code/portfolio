# Agent QA Console

A bounded product-operations sample built against the public responsibilities in EvenUp's Product Operations Associate listing.

## What it demonstrates

- A synthetic regression suite for an AI communication agent
- A risk-weighted QA rubric
- Explicit pass, review, and blocker decisions
- A failure taxonomy and next-action owner
- A concise go/no-go release memo

## Product decision

The sample release is held because two blocker-class failures remain: an unsupported factual claim and a missed urgent escalation. The smallest safe patch is stated, and the release gate requires a score of at least 90 with zero blockers.

## Scope and privacy

All scenarios and outputs are synthetic. No EvenUp, client, legal, medical, or personal data is used. The artifact demonstrates a method, not knowledge of EvenUp's internal systems.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.
