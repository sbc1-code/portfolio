TWO-DAY EXPERIMENT MEMO

Ship the smallest fix that proves whether clearer state reduces customer work.

The evidence supports a narrow experiment: expose a verified payment state and use the same state to answer routine status questions. Do not rebuild the payments surface or automate exceptions yet.

Change

Add plain-language state, latest-event timestamp, and a review route when transaction evidence is missing or conflicting.

Primary metric

Reduce repeat payment-status contacts by at least 25% among exposed customers over two weeks.

Guardrail

Zero false “completed” responses. Any evidence conflict must route to human review.

Decision rule

Scale if the contact rate falls and accuracy holds; revise if comprehension improves but repeat contacts remain; stop on any false completion.
