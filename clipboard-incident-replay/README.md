# One request. Twice.

An independent work sample by Sebastian Becerra for Clipboard’s Strategy & Ops Lead, Applied AI role.

Interactive incident replay: duplicate support events, event identity, connector outages, queued recovery, lost acknowledgments and human review. Inspect the event ledger and export a change brief with acceptance criteria and pilot measures.

All events are fictional. The AI example is prepared, not a live model response. This standalone browser prototype does not connect to Clipboard or a support platform, and does not demonstrate production concurrency.

Open index.html locally or visit https://sbc1-code.github.io/portfolio/clipboard-incident-replay/ . No installation or API key is required.
