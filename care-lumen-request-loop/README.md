# Request-to-Release Loop

A small, role-specific Product Operations proof built from public responsibilities for Care Lumen's Product Operations Specialist opening.

The prototype demonstrates a bounded operating loop:

1. Capture and cluster synthetic product requests.
2. Mature one request into a problem statement, definition of done, guardrail, and measurement plan.
3. Expose delivery gates and dependencies across the PDLC.
4. Run a synthetic rollout and make a scale, revise, or stop decision.

All workflow data is synthetic. The project contains no Care Lumen customer, clinical, patient, or internal company data.

## Run locally

Open `index.html`, or serve the directory with any static file server.
