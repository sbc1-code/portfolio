Developer launch brief · November 7, 2026

Shipping an agent with Render Sandboxes

Run your agent’s code in a Render Sandbox and download the finished files before terminating it. Give the editor access to the downloaded copies.

What ships today

In public beta, your agent can run commands and generated code in a managed, isolated Render Sandbox. You can operate the sandbox through the Render CLI or the TypeScript and Python SDKs.

S1S3

How the editor keeps access

Files persist between commands and while the sandbox is suspended. Termination permanently deletes the sandbox’s filesystem, so download the finished files first and share the copies for the editor to open afterward.

S1S2

Beta boundaries

Render Sandboxes are in public beta. Shared Filesystems are in early access. Private networking to other Render services and public URLs for applications running inside a sandbox are currently unavailable.
