# Retinal anatomy illustration

Source: Kristen Browne and Heidi Schlehlein, *3D Reference Organ for Eye, Male, Left v1.2* (2023), Human Reference Atlas / HuBMAP.

Source and DOI: https://doi.org/10.48539/HBM858.KCTG.666
License: CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/

Adaptation: Selected meshes, centered/rescaled, simplified, recomputed smooth normals, removed vertex colors, and added illustrative front-projected UVs.

Output: 621,324 bytes, 28,034 triangles, four source meshes. See retinal-anatomy.metadata.json for reproducible source/output checksums.

Independent illustrative website sample. Not an Optos digital twin or clinical scan. No NIH, HuBMAP, or creator endorsement is implied. Not for diagnosis or treatment. Microscopic retinal layers are not modeled. Runtime materials/lighting and any optional generated illustration texture are additional presentation changes.

Rebuild privately with: node scripts/prepare-anatomy.mjs
The original source is retained outside the public directory.
