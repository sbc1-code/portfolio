# Samsara refrigerated-load evaluation prototype

Independent portfolio sample by Sebastian Becerra. Working review version, October 27, 2026 UTC. Not an official Samsara page or a product change.

## Working experience

Open `index.html` through an ordinary static web server. Three native HTML disclosures reveal equipment/connection questions, information and alert questions, and requested demonstration topics in the product-page context. The first starts open; every disclosure can be opened/closed by pointer, Enter or Space without JavaScript. Sales links remain separate and go to the official Samsara site. There is no local form, tracking, local storage or collected personal information.

## Research and scope

The current Mexican refrigerated-monitoring page's five contextual “more information” links share `/mx/learn-more`, which redirects to the trial/qualification route. This sample adds educational exploration; it does not claim measured conversion loss, representative customer research or a missing product capability. Samsara already describes temperature monitoring, alerts and records.

Public sources:

- https://www.samsara.com/mx/products/equipment-tracking/reefer-monitoring
- https://www.samsara.com/mx/guides/fleet-faq
- https://kb.samsara.com/hc/es/articles/360053620411-Instalaci%C3%B3n-de-AG26-en-un-contenedor-refrigerado-Carrier
- https://www.samsara.com/customers/simco-logistics
- https://gomotive.com/es-mx/productos/monitoreo-de-refrigerados/

Motive's inline FAQ treatment informed the placement of evaluation requirements; it does not establish superiority or equivalent technical requirements. Simco is a Samsara-selected US customer case, not independent Mexican results. Carrier's public guide includes a CDG/cable end-of-sale warning. Current model/account/region/connection requirements must be confirmed with Samsara.

The three sections contain questions, not a compatibility checker, installation recommendation, live data feed, ROI calculator, compliance decision, prescribed temperature threshold or validation protocol.

## Visual implementation

The current public product page supplies the black/white/neutral/yellow visual system, typography direction, original hero photograph and recognizable header/hero. The new section uses open disclosure rows rather than a card grid or dashboard. The original email capture is replaced with a non-collecting sales link. Mega menus, search and account controls are omitted; navigation is direct public links. The page is a bounded representative slice, not a full clone.

`assets/reefer-header.avif` is the original public product hero. The logo asset is the public source brand mark. FK Grotesk font references point to Samsara's public font URLs; no font files are redistributed. Arial/Helvetica are explicit fallbacks if cross-origin fonts are unavailable. Local images avoid runtime dependencies for the hero and brand mark.
