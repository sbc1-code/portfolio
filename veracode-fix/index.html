The difference is in how input is handled.

Illustrative Java example · SQL injection

Before · input becomes SQL

1String sql =2    "SELECT id FROM customers " +3−    "WHERE name = '" + name + "'";4−Statement query = db.createStatement();5−ResultSet rows = query.executeQuery(sql);

After · input stays data

1String sql =2    "SELECT id FROM customers " +3+    "WHERE name = ?";4+PreparedStatement query = db.prepareStatement(sql);5+query.setString(1, name);6+ResultSet rows = query.executeQuery();
A name should be data, not an instruction.

Before: the name is joined directly to the SQL query. Specially crafted input can change what the query asks the database to do.
