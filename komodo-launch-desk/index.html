What supports this campaign.

Why this workflow

I made this so a Revenue Marketing team can turn a product update into a reviewable campaign page with reusable WordPress sections. The same message can move from preview to an editable draft without rebuilding the page.

What this version demonstrates

Prepared copy variants, editable page sections, tagged links, portable HTML, WordPress blocks, and a real local draft save with readback.

Verified November 9: 20 functional checks passed. Local WordPress saved draft #4 with 32 blocks; the stored title and content matched the reviewed input. The test covered restart persistence and repeat saves without duplicate pages.

How it was made

Sebastian selected the problem, directed the concept, and reviewed the first working version. OpenAI Codex assisted with implementation and testing. The sample uses prepared templates; it makes no model calls.

What it does not claim

No live AI generation, automatic fact-checking, CRM connection, measured conversion improvement, or employer approval. All source statements are Komodo’s public claims. This is an independent candidate sample.
